## 🎯 Бизнес-проблема

Компании часто сталкиваются с необходимостью переноса данных из легаси-систем (1С, Excel, веб-интерфейсы), **не имеющих API или ETL-коннекторов**. Традиционные инструменты (Talend, NiFi) не решают задачу напрямую, так как требуют доступа к БД или стабильных интерфейсов.  
**Решение:** использование RPA как моста между «чёрным ящиком» и современным хранилищем.

Сценарий реализует ключевые принципы из научной статьи:
- ✅ **Предварительная оценка совместимости** — ручная/автоматическая проверка структуры источника.
- ✅ **Параллельная обработка с маркировкой** — каждая строка помечается как "обработана".
- ✅ **Промежуточное хранилище** — данные проходят валидацию перед загрузкой в целевую систему.
- ✅ **Отказоустойчивость** — при сбое процесс возобновляется с последней метки.

## ⚙️ Технологический стек

- **RPA-платформа**: [Росплатформа RPA](https://rosplatforma.ru/) (внесена в [Единый реестр Минцифры РФ](https://reestr.minsvyaz.ru))
- **Промежуточное хранилище**: PostgreSQL / CSV
- **Целевая система**: Google Таблицы / ClickHouse / REST API (Mock)
- **Дополнительно**: Python (для трансформации), Airflow (оркестрация — при наличии)

## 📂 Структура проекта

```
├── rpa-scripts/               # Исходники ботов (файлы .rpz или .exe)
├── sample-data/               # Примеры исходных данных (Excel, CSV)
├── transformed-data/          # Результат после валидации
├── logs/                      # Логи выполнения
├── docs/                      # Схема архитектуры, скриншоты
└── demo-video.mp4             # Краткая демонстрация (1-2 мин)
```

## ▶️ Как запустить

1. Установите **«Росплатформа RPA Studio»** (демо-версия доступна на [официальном сайте](https://rosplatforma.ru/)).
2. Откройте проект из папки `rpa-scripts`.
3. Настройте пути к исходным и целевым файлам.
4. Запустите сценарий.

> ⚠️ Для работы с веб-интерфейсами убедитесь, что сайт доступен и не меняет верстку.

## 🌐 Список демо-сайтов для практики RPA (без регистрации, с формами)

Используй эти сайты, чтобы тренировать **клики, ввод текста, выгрузку данных**:

### 1. **Демо-версии 1С**
- [https://demo.1c.ru/](https://demo.1c.ru/) — официальный демо-сайт 1С:Предприятие (вход без логина).
- [https://v8.1c.ru/demo/](https://v8.1c.ru/demo/) — интерактивные демо-ролики (можно эмулировать ввод).

### 2. **Публичные реестры и формы**
- [https://egrul.nalog.ru/](https://egrul.nalog.ru/) — поиск по ИНН/ОГРН (ввод → получение данных).
- [https://www.gosuslugi.ru/](https://www.gosuslugi.ru/) → «Каталог услуг» → любая форма (например, запись к врачу).
- [https://rosreestr.gov.ru/](https://rosreestr.gov.ru/) → «Сервисы» → «Справочная информация по объектам недвижимости».

### 3. **Тестовые веб-формы (для отработки селекторов)**
- [https://demoqa.com/text-box](https://demoqa.com/text-box) — простая форма ввода (отлично для начала).
- [https://the-internet.herokuapp.com/](https://the-internet.herokuapp.com/) → «Form Authentication», «Dynamic Controls» и др.
- [https://www.selenium.dev/selenium/web/forms.html](https://www.selenium.dev/selenium/web/forms.html) — классическая тестовая форма.

### 4. **Имитация легаси-интерфейсов**
- Любой сайт с таблицами: [https://www.worldometers.info/world-population/](https://www.worldometers.info/world-population/)
- Старые HTML-сайты (без JavaScript): [https://www.textfiles.com/](https://www.textfiles.com/)

> 💡 **Совет**: Используй **браузер в режиме «старой версии»** (например, через DevTools → Network → User-Agent → IE11), чтобы имитировать корпоративные легаси-системы.
